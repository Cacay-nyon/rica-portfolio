# Rica Aniñon — Creative Virtual Assistant

A responsive portfolio in blue, pastel blue, and white, featuring Rica’s real design work, video editing, and social media support.

## Preview

Open `index.html` in a browser, or serve this folder with any static web server. No build step or package installation is required.

## Files

- `index.html`: page content, accessibility structure, and SEO metadata.
- `styles.css` and `creative.css`: layout, responsive styling, and creative gallery compositions.
- `script.js`: project previews, theme toggle, mobile navigation, and WhatsApp inquiry draft.
- `creative.js`: artwork motion, scroll reveals, reduced-motion support.
- `assets/`: portfolio images, video sample, and CV.
- `COPY.md`: reusable website copy.

## Contact

The inquiry form opens a WhatsApp draft. Visitors review and send it in WhatsApp; this website does not store submissions.

## Deployment

This is a static website. Configure your hosting service to publish the repository root with no build command. Live portfolio: https://cacay-nyon.github.io/rica-portfolio/ (GitHub Pages, main branch, repository root).

The canonical and Open Graph URLs point to the live GitHub Pages portfolio.

## Design and content

Includes the September 22 creative redesign: fanned artwork, a portrait collage, staggered projects, and reduced-motion support. Layout references are not included as portfolio work. All displayed work assets come from Rica’s existing portfolio.

## App content and motion update

Nine Nibbles social designs are featured in the App content section, with expandable browsing and previous/next image previews. The final concept retains its original production note. Images use optimized WebP files with their original dimensions. refinements.css adds the new gallery and spacing. Motion eases toward scroll position, stops when idle, and disables parallax on small screens. The opening Pause motion / Scroll to explore strip was removed. Operating-system reduced-motion preferences remain supported.
