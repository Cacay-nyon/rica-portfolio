# Rica Aniñon — Creative Virtual Assistant

A responsive portfolio in blue, pastel blue, and white, featuring Rica’s real design work, video editing, and social media support.

## Preview

Open `index.html` in a browser, or serve this folder with any static web server. No build step or package installation is required.

## Files

- `index.html`: page content, accessibility structure, and SEO metadata.
- `styles.css` and `creative.css`: layout, responsive styling, and creative gallery compositions.
- `script.js`: project previews, theme toggle, mobile navigation, and WhatsApp inquiry draft.
- `creative.js`: artwork motion, scroll reveals, pause control, and reduced-motion support.
- `assets/`: portfolio images, video sample, and CV.
- `COPY.md`: reusable website copy.

## Contact

The inquiry form opens a WhatsApp draft. Visitors review and send it in WhatsApp; this website does not store submissions.

## Deployment

This is a static website. Configure your hosting service to publish the repository root with no build command. Repository upload alone does not publish a live website.

Once a final public domain is selected, add its canonical URL and Open Graph URL to `index.html`, and create the corresponding sitemap and robots file. Old preview-domain references have been removed from this copy.

## Design and content

Includes the September 22 creative redesign: fanned artwork, a portrait collage, staggered projects, and accessible motion controls. Layout references are not included as portfolio work. All displayed work assets come from Rica’s existing portfolio.
